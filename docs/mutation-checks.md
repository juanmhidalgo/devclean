# Mutation checks

Every safety test in devclean was shown to fail when the bug it guards against
is reintroduced (AC-43). For each one, the code under test was temporarily
mutated, the test was run, and the failing assertion was recorded below. The
mutation was then reverted.

The checks are manual. Redo the matching row whenever the test or the code
under test changes. Each named test carries a `// MUTATION:` comment next to
the row or assertion that catches the mutation.
